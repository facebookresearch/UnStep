# README figures and samples

`method.png` is the method figure from the UnStep paper, exported for display
on GitHub. The sample strips are existing Self Forcing + UnStep outputs shown
in the paper, using the default two-step wrapper and extended VBench prompts.
Each strip shows frames 0, 20, 40, 60, and 80 of an 81-frame video.

| File | VBench entry index | Original prompt |
| --- | --- | --- |
| `cyberpunk_corgi.jpg` | 534 | A cute happy Corgi playing in park, sunset, in cyberpunk style |
| `fantasy_rabbit.jpg` | 690 | A fat rabbit wearing a purple robe walking through a fantasy landscape. |
| `raccoon_guitar.jpg` | 757 | A cute raccoon playing guitar in a boat on the ocean |

The images are display assets. Model files, benchmark data, and source
dependencies are downloaded separately as described in [installation](../installation/).
