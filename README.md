<h1 align="center">UnStep</h1>

<p align="center"><b>Training-Free Acceleration of Causal Video Diffusion</b></p>

<p align="center">
  <b>50 FPS on a single H100 &nbsp; · &nbsp; 64 FPS on GB200</b><br>
  Default two-step wrapper &nbsp; · &nbsp; 832 × 480 &nbsp; · &nbsp; No retraining<br>
  <sub>One step: 60 FPS on H100 and 77 FPS on GB200. Speeds rounded as in the paper.</sub>
</p>

UnStep accelerates existing Self Forcing and Causal Forcing checkpoints at inference. It combines fewer denoising steps and a smaller KV attention window with clean-cache refinement, truncated SVD, and an optimized DiT/VAE runtime stack.
