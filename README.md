<p align="center">
  <b>50 FPS on a single H100 &nbsp; · &nbsp; 64 FPS on GB200</b><br>
  Default two-step wrapper &nbsp; · &nbsp; 832 × 480 &nbsp; · &nbsp; No retraining<br>
  <sub>One step: 60 FPS on H100 and 77 FPS on GB200.</sub>
</p>

UnStep accelerates existing few-step causal video models based on Wan 2.1, entirely at inference. It combines fewer denoising steps and a smaller KV attention window with clean-cache refinement, truncated SVD, and an optimized DiT/VAE runtime stack.

## Results

## Image-to-video

UnStep supports image-conditioned generation without task-specific retuning. The paper evaluates 1,118 image-prompt pairs from 355 reference images using VBench-I2V's official 16:9 crops, at 832 x 480 and 16 FPS.

See the [I2V guide](generation/i2v.md) for image downloads, generation, and evaluation.

## Long video

The paper evaluates 30.56-second clips on VBench++'s 40-prompt long-video competition track. UnStep keeps the same method settings and uses blockwise VAE decoding for longer clips.

See the [long-video guide](generation/long_video.md) for duration controls, generation, and evaluation.
